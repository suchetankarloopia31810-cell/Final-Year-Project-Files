# Reference PDFs — Access Index

This index lists every reference cited in the Journal of Building Engineering
manuscript (`Generated_Report/Journal_Paper/JBE_Manuscript_BioComposites.docx`),
together with a direct link to obtain the PDF.

**Why links instead of files?** Automated downloading of the PDFs was attempted
but the publisher servers block non-browser requests (MDPI returns Akamai
"Access Denied"; Hindawi serves a Cloudflare challenge). These links open
normally in a regular web browser. Open-access status was verified with the
[Unpaywall API](https://unpaywall.org/).

- **Open access (free):** click the "PDF" link to download directly.
- **Subscription / paywalled:** the full text is not free to redistribute.
  Use the DOI link and sign in through your **NIT Srinagar institutional
  access** (library proxy), or request a copy from the authors via ResearchGate.
